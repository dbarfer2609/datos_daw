## 1) Caso
- Sistema: Sistema de control de asistencia escolar digital.
- Contexto: La escuela necesita registrar la asistencia diaria de los alumnos para mejorar el seguimiento académico y detectar ausencias frecuentes.

## 2) Datos
- Nombre del alumno.
- Fecha de asistencia.
- Hora de entrada y salida.
- Motivo de ausencia.

## 3) Información
- Porcentaje de asistencia por alumno.
- Alumnos con ausencias frecuentes.
- Días con mayor índice de faltas.

## 4) Diferencia
- Dato: "Pablo Ruiz, 06/04/2026, 06:00 AM - 04:00 PM"
- Información: Pablo tiene un 40% de asistencia mensual; se recomienda seguimiento academico"

## 5) Ciclo del dato
- Captura: Registro diario de asistencia mediante lector de tarjetas o app.
- Almacenamiento: Base de datos de la escuela.
- Procesamiento: Cálculo de asistencia porcentual y generación de alertas.
- Análisis: Identificación de alumnos con ausencias frecuentes o patrones de inasistencia.
- Uso: Comunicación con padres, seguimiento académico, planificación de tutorías.
- Eliminación: Depuración de registros de asistencia después de 5 años según la normativa educativa.

## 6) Aplicación
- Decisiones: Contactar padres de alumnos con faltas frecuentes; organizar tutorías; ajustar planes de estudio.
- Valor: Mejora del rendimiento académico y reducción de ausencias injustificadas.

## 8) Diagrama

```
    Captura --> Almacenamiento --> Procesamiento --> Análisis --> Uso --> Eliminación
```

## 9) Problemas
- Problema 1: Datos de asistencia manuales causan errores.
- Solución 1: Implementar sistema digital con lectura automática.
- Problema 2: Dificultad para identificar alumnos con patrones de inasistencia.
- Solución 2: Generar reportes automáticos de asistencia mensual.
